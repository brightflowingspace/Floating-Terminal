# Floating Terminal

常に他のウインドウより手前に表示できる、macOS 用のターミナルアプリです。
標準の「ターミナル」はそのままに、別アプリとして同時に使えます。

中身は [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm) で、ログインシェル（zsh など）をそのまま動かします。Claude Code などのコマンドもふだんどおり使えます。

## できること

- 常に手前に表示（ON/OFF 切り替え）
- フルスクリーンのアプリの上にも重ねて表示
- タブ（タブごとに別のシェルが動きます）
- 透過度の変更（透過0% / ターミナルと同じ / 10%〜70%）
- 今のフォルダを標準の「ターミナル」で開く
- 設定メニューから標準の「ターミナル」の設定画面を開く
- 標準の「ターミナル」の設定を起動時に読み込んで反映
- ウインドウの位置と大きさ、手前表示、透過の設定を次回起動時も保持

## ショートカット

- ⌘⇧T … 常に手前に表示の ON/OFF
- ⌘T … 新しいタブ（今のタブと同じフォルダで開きます）
- ⌘W … タブを閉じる
- ⌘= … 透過を減らす（いちばん上は透過0%）
- ⌘- … 透過を増やす
- ⌘, … 標準の「ターミナル」の設定画面を開く
- ⌘C / ⌘V … コピー / ペースト
- ⌘Q … 終了

手前表示を OFF にしても、操作中は手前に出たままです。他のアプリをクリックしたときに後ろへ回ります。
手前表示と透過は、すべてのタブで共通です。

シェルで exit するとそのタブが閉じ、最後のタブを閉じるとアプリも終了します。

## メニュー

- Floating Terminal ＞ 設定… … 標準の「ターミナル」の設定画面を開きます
- シェル ＞ 新規タブ
- シェル ＞ このフォルダをターミナルで開く … 今のタブのフォルダで、標準の「ターミナル」の新しいウインドウを開きます
- シェル ＞ タブを閉じる
- 表示 ＞ 常に手前に表示 / 不透明にする / 透明にする
- ウインドウ … タブの切り替えなど（macOS が自動で追加します）

## 画面下部の表示

標準の「ターミナル」と見分けられるよう、画面の一番下に次のように表示します。

```
Floating Terminal v1.0.0　⌘ 常に手前に表示：[ON]（⌘⇧T でOFF）　透過：0%（⌘- / ⌘=）
```

ON / OFF の部分は、文字色の背景で目立つように表示します。

## 標準の「ターミナル」から反映する設定

「ターミナル」の 設定 > プロファイル で「デフォルト」にしているプロファイルを、起動時に読み込みます。
「ターミナル」側で設定を変えたら、Floating Terminal を開き直すと反映されます。

反映するもの

- 背景色、文字色、カーソル色、選択範囲の色
- 16色のカラーパレット
- フォントと大きさ（等幅でないフォントは、同じ大きさの SF Mono に置き換えます）
- 背景の透過とぼかし
- 行間
- カーソルの形（ブロック / 下線 / 縦線）と点滅
- ベル（音 / 画面フラッシュ）
- Option キーをメタキーとして使用

反映しないもの

- 字間
- 太字フォントを使うかどうか、太字を明るい色で表示するかどうか
- 「デフォルト」以外のプロファイル

## 動作環境

- macOS 13 以降
- ビルドには Xcode（または Command Line Tools）の Swift が必要です

## ビルドとインストール

```
./build_app.sh
```

同じフォルダに `Floating Terminal.app` ができます。アプリケーションフォルダで使う場合はコピーしてください。

```
cp -R "Floating Terminal.app" /Applications/
```

ビルドの途中でできる作業ファイルは `~/Library/Caches/FloatingTerminal-build` に置かれます。
バージョン番号は `build_app.sh` の `CFBundleShortVersionString` で設定し、画面下部の表示にも使われます。

## アイコン

アイコンは `make_icon.swift` で描いています（`>` `<` の目と `F` の口の顔）。描き直すときは次を実行してから、`AppIcon.icns` を作り直してください。

```
swift make_icon.swift AppIcon.png
```

## 注意

- 設定メニューは、標準の「ターミナル」を前面に出してから ⌘, を送る仕組みです。初めて使うときに、システム設定 ＞ プライバシーとセキュリティ ＞ アクセシビリティ で Floating Terminal の許可が必要です。許可がない場合は「ターミナル」が前面に出るだけになります。
- 署名は自分の Mac 用の簡易署名（ad-hoc）です。ビルドし直すとアクセシビリティの許可が外れることがあり、そのときは許可し直してください。他の Mac で開くと、macOS の警告が出ることがあります。
- 背景のぼかしは、macOS の非公開の機能を使っています。将来の macOS で効かなくなった場合も、ぼかしがなくなるだけでアプリは動きます。

## ファイル構成

- `Sources/FloatingTerminal/main.swift` … アプリ本体
- `Package.swift` / `Package.resolved` … 使っている部品（SwiftTerm）の設定
- `build_app.sh` … ビルドして .app を作るスクリプト
- `make_icon.swift` … アイコンを描くスクリプト
- `AppIcon.png` / `AppIcon.icns` … アイコン
